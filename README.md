# FlowMind AI
An AI-powered CFD simulation, prediction, and optimization platform.
## Project Objectives
- CFD surrogate modeling using Deep Learning
- Physics-Informed Neural Networks (PINNs)
- Fourier Neural Operators (FNO)
- AI-driven engineering optimization
- Agentic AI and RAG
- REST API development using FastAPI
- Interactive CFD visualization
## Technologies
Python, PyTorch, OpenFOAM, FastAPI, LangGraph
